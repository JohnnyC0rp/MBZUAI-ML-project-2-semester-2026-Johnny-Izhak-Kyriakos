\section{Model Selection \& Final Pipeline}

Once the feature set stopped changing, model selection became easier to organize. The branch search followed one simple rule: keep model families only when they added either stronger single-model performance or genuinely different errors. The final submission combined five branches:
\begin{enumerate}
    \item XGBoost on the shared engineered numeric matrix;
    \item LightGBM on the same matrix, with a different boosting bias;
    \item CatBoost on the mixed table with categorical columns preserved as categories;
    \item ExtraTrees as a weaker but diverse non-boosted tree baseline;
    \item a compact MPS neural branch trained jointly for classification and regression.
\end{enumerate}

Table~\ref{tab:model-table} summarizes the main saved checkpoints from this search. Among the single branches, LightGBM and CatBoost gave the most balanced results, while the MPS branch was useful because its mistakes were less aligned with the tree branches. ExtraTrees was clearly weaker on its own, but keeping one simpler branch still helped the combined models by adding diversity. The best submitted solution was not the weighted average but the meta-ensemble, which stacked branch outputs with a logistic classifier for Task A and a ridge regressor for Task B.

\textbf{Overfitting control.} Every branch was compared on the same stratified split, the interaction set was kept deliberately small, and the tree models were tuned under fixed time budgets before refitting only the selected settings. The MPS branch added dropout, weight decay, gradient clipping, and patience-based early stopping, while the meta-ensemble tuned its logistic and ridge combiners through cross-validation rather than an unrestricted second-level learner.

\textbf{Do the same features matter equally for both tasks?} Broadly yes, but not in exactly the same form. Both targets depend on delinquency history, derogatory marks, and utilization; however, classification reacts more directly to raw counts, whereas regression leans more strongly on interaction terms such as \texttt{LateSeverityXUtilization}. This is why every branch kept separate classification and regression heads until the final submission stage.

\textbf{Final submitted pipeline.} Inference proceeds in five steps: build the shared engineered table; train XGBoost, LightGBM, CatBoost, ExtraTrees, and the multitask MPS branch on the saved overnight settings; collect branch probabilities and rate predictions; fit the logistic and ridge meta-combiners; then clip the final APR to \([4.99, 35.99]\) and round it to two decimals.

This \texttt{meta\_overnight} lane reached a combined local validation score of \publicscore. Later local research branches pushed the score higher, but the submitted model remained the cleanest fully specified pipeline for the assignment deliverable.
